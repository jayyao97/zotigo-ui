# 使用 Desktop 和 Web

本指南介绍界面中那些在 [README](../../README.zh-CN.md) 里一句话说不清的部分：主机、搜索、文件面板、Codex
会话、设置和键盘快捷键。Desktop 和 Web 使用相同的界面；两者有差异的地方会单独说明。

## 主机

主机是客户端所连接的一个 `zotigod`。每个客户端都内置一个 **Local** 主机（与 Desktop
在同一台机器上的 daemon，或 Web 服务器上的 daemon），并且可以保存远程主机。

### 添加远程主机

1. 打开左上角的主机菜单，选择 **设置**（或按 ⌘, / Ctrl+,）。
2. 在 **通用 → 连接** 下点击 **管理**。
3. 填写名称、daemon 地址（例如 `http://dev:8766`）和它的 daemon 令牌，然后点击 **测试**。
4. 在主机菜单中选择刚保存的主机。

地址必须是 daemon 可访问的地址，不能是 `0.0.0.0`，也不能是 Web UI 的 URL。远程 daemon
的版本必须足够新，能够提供目录浏览和 `/files/capabilities`；较旧的版本会显示升级提示。可以在
**设置 → 版本与更新** 中更新它。

### 切换主机的效果

项目、来源检查、工作区创建、会话、事件、图片和文件编辑都使用所选的 daemon，文件路径指的是该
daemon 所在机器上的路径。切换主机时会先检查连接，在丢弃草稿或未保存的编辑之前询问确认，并清空上一个主机的视图。切换不会停止任何一个
daemon 上已经在运行的工作。

Desktop 按设备记住所选主机；Web 按浏览器标签页记住。会话的选中状态和排序按主机分别保存。

### 配置和令牌的存储位置

保存的主机及其 daemon 令牌存放在一个仅所有者可访问的 `hosts.json` 中，与后端偏好设置放在一起：Web
使用 `ZOTIGO_WEB_DATA_DIR`（默认 `~/.zotigo/web`），Desktop 使用 Electron
的用户数据目录。配置列表从不返回令牌。在 Web 服务器上，保存的主机由该服务器的所有已登录用户共享，但在一个标签页中切换主机不会影响另一个标签页。

重命名主机会保留它的身份。修改地址或令牌则会替换该主机，因此其他 Web
标签页必须重新加载并重新选择它。如果修改的是当前连接的地址或令牌，客户端会先切换到
Local。Local 主机本身由启动环境配置，不能在这里编辑。

浏览器与它的 Web 后端通信，后端再与所选 daemon 通信。Desktop 通过主进程连接。两者都使用带
bearer 认证的 HTTP(S)；不使用 SSH 隧道。在可信网络之外请使用 HTTPS，因为普通 HTTP
不会加密 daemon 令牌。Web 登录和 daemon 认证是相互独立的。

旧版客户端会忽略已保存主机的字段，并保留 `hosts.json` 不动；它们无法使用远程配置。

## 搜索

按 ⌘K / Ctrl+K，或点击侧边栏中的搜索图标。搜索面板会按标题、项目或工作区搜索当前主机上的最近会话，列出匹配的工作区，并提供创建会话或项目等快捷操作。用方向键和
Enter 打开结果，按 Esc 关闭。

在会话中按 ⌘F / Ctrl+F 可以搜索其中的消息，包括尚未加载的消息。

## 添加项目文件夹

文件夹通过一个目录浏览器选择，它读取的是所选 daemon 的文件系统，Local 和 Desktop
也是如此；不使用系统原生的文件夹对话框。可以进入某个目录、返回上级目录、选择多个文件夹，或使用当前文件夹。目录列表最多显示
1,000 个条目，超出时会显示提示。

## 文件面板

打开右上角的侧边面板并选择 **浏览文件**，或按 ⌘P / Ctrl+P。⌘⌥B / Ctrl+Alt+B
显示或隐藏侧边面板。项目路径、工作区的 **浏览文件**、产物、笔记以及 Markdown
中的目录链接都会打开同一个面板。

- 工作区文件树位于文件标签页旁边。面板可以调整大小、展开或隐藏，不会关闭已打开的文件。
- Markdown 以预览方式打开，可以切换到源码编辑，并自动保存。其他文本文件在编辑器中打开；按 ⌘S / Ctrl+S
  保存。
- 图片和视频在查看器标签页中打开。不支持其他二进制文件。
- 文本文件最大可预览 5 MiB、编辑 1 MiB。如果文件打开后在磁盘上被改动过，保存会被拒绝。
- 文件名筛选只作用于已加载的条目。展开文件夹或刷新可以更新列表。
- 在同一主机上切换会话时，已打开的文件和草稿会保留，但重新加载应用后不会恢复标签页。

会话详情可以通过右上角的详情按钮查看。

## 对话

- 输入框有两种发送模式：**立即引导** 把消息加入正在运行的轮次，**加入下一轮队列**
  在当前轮次结束后再发送。⌘Enter / Ctrl+Enter 使用另一种模式；默认模式在
  **设置 → 通用** 中设置。
- 工具调用、审批、子 Agent、Markdown、Mermaid 图和图片都在消息流中直接渲染。审批请求可以批准，也可以拒绝并附上可选的理由。每个会话有自己的审批模式（手动、自动或完全访问）。
- 选中的会话文本可以翻译成 **设置 → 通用 → 翻译目标语言** 中选择的语言。
- 可以在消息中附加图片；图片会上传到所选的 daemon。

## Codex 会话

当 daemon 能找到 `codex` 可执行文件时，新会话可以使用 Codex 代替 Zotigo Agent。Codex
使用自己的登录信息和模型目录；**设置 → 模型配置** 中的 API 配置对它没有影响。**设置 → 通用 →
同步会话** 会从主机导入最近的 Codex 会话，模型配置页面可以重新加载 Codex 模型列表。

导入的 Codex 消息如果包含截图，会在原始请求上方显示图片缩略图。只有当生成的附件文本中的文件路径与记录的图片一致时，这段文本才会被隐藏。图片通过所选
daemon 的认证图片 API 获取，而不是从客户端机器上读取。如果原始临时文件已被删除，缩略图会显示为不可用状态，并提供重试选项。

daemon 发现 Codex 的规则见
[daemon 安装指南](https://github.com/jayyao97/zotigo/blob/master/docs/zh-CN/installation.md#后台服务中的-codex-探测)中关于后台服务中
Codex 发现的一节。

## 频道

侧边栏中的 **频道** 页面用于把飞书/Lark 机器人连接到 daemon，列出机器人所在的群组，并把某个群组或话题绑定到工作区或会话。连接由
daemon 维护，所以客户端关闭后它仍然可以工作。字段级别的行为（发送者策略、`/bind`、进度详情）见
[zotigod API 参考](https://github.com/jayyao97/zotigo/blob/master/docs/zotigod-api.md#channels)（英文）。

## 设置

按 ⌘, / Ctrl+, 或从主机菜单打开。按 Esc 返回会话。

| 页面 | 内容 |
| --- | --- |
| 通用 | 界面语言（English 或简体中文）、默认发送模式、翻译目标语言、思考内容显示、侧边栏中的频道活动、会话同步、连接（主机）、性能诊断 |
| 模型配置 | 所选主机上的模型配置、连接测试、收藏模型、刷新 Codex 模型 |
| 用量 | 随时间变化的 token 活动，可按模型和来源（是否来自频道）筛选，并提供按会话的排名 |
| 版本与更新 | 已安装的客户端和 daemon 版本、正式版或开发版更新渠道、检查、准备和应用更新 |

更新的说明见 daemon 的
[应用更新](https://github.com/jayyao97/zotigo/blob/master/docs/zh-CN/application-updates.md)
指南。应用更新时，Desktop 会退出并自动重新启动。
